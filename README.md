# Grain & Type

A browser-only photo tool: add film grain and a display-serif headline to any photo, then export at full resolution.

## Features

- **Grain:** ISO 100 / 400 / 1600 / 3200 presets, amount, grain size, midtone bias, optional color grain, new-pattern reroll. Grain scales with resolution, so the export matches the preview.
- **Text:** add as many text boxes as you need. Click a box on the photo to select it, drag it to move (snaps to center), drag a corner or side handle to resize the text. Delete removes the selected box, Esc deselects, double-click jumps to editing its text. Each box has its own typeface (Fraunces Heavy by default, plus Fraunces Thin, Light, Regular and Black, plus DM Serif Display, Young Serif, Gloock, Playfair Display and Abril Fatface), size, tracking, leading, alignment, color and soft shadow. Grain can sit over or under the text.
- **Input:** open, drag and drop, or paste an image.
- **Export:** full-resolution JPEG (quality 92) or PNG, via Download or Copy image.
- **Privacy:** everything runs in the browser. Nothing is uploaded.

## Run it

Open `index.html` in a browser. Fonts load from Google Fonts, so an internet connection is needed for the typefaces; offline it falls back to Georgia.

To host it, put `index.html` on any static host (for example GitHub Pages).
